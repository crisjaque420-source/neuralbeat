## 🔬 Fundamento Científico

### Frecuencias Binaurales
**Mecanismo**: Dos tonos ligeramente diferentes presentados a cada oído. El cerebro percibe la diferencia como un tercer tono (beat).

**Evidencia**:
- Meta-análisis 2025 (Cooper & Hawk) - 15 RCTs, +1000 pacientes
- Reducción significativa de ansiedad perioperatoria, dolor y presión arterial
- Efectos más robustos en sistema nervioso autónomo que en arrastre EEG directo

**Referencia**: Cooper & Hawk (2025). *Scientific Reports*, 15, 4308.

### Coherencia Cardíaca
**Mecanismo**: Respiración a 0.1 Hz (6 rpm) maximiza la variabilidad de frecuencia cardíaca (HRV) y la señal vagal.

**Evidencia**:
- Neuroscience 2025 (Ferrer-Uris et al.)
- HRV mediada vagalmente correlaciona con mejor función ejecutiva, memoria y atención
- El nervio vago tiene >80% de fibras aferentes (cuerpo→cerebro)

**Referencia**: Ferrer-Uris et al. (2025). *Neuroscience*, 565, 369–376.

### Pranayama y LCR
**Mecanismo**: La respiración consciente modifica el flujo pulsátil del líquido cefalorraquídeo (LCR).

**Evidencia**:
- Oregon Health & Science University 2022
- MRI en tiempo real demuestra que pranayama altera inmediatamente el flujo de LCR
- Las retenciones (Kumbhaka) generan cambios de presión intracraneal

**Referencia**: Yildiz et al. (2022). *Scientific Reports*, 12, 10666.

### Gamma 40 Hz (Protocolo MIT)
**Mecanismo**: Estimulación multisensorial a 40 Hz sincroniza células gliales y activa el sistema glinfático.

**Evidencia**:
- MIT Tsai Lab 2016-2023
- Reducción de placas amiloides 40-50% en modelos de Alzheimer
- Activación de microglía y astrocitos para limpieza cerebral

**Referencia**: Iaccarino et al. (2016). *Nature*, 540, 230–235.

### Wim Hof Method
**Mecanismo**: Hiperventilación controlada → hipocapnia → alcalinización pH → retención vacía → hipoxia-hipercapnia → activación simpático-adrenal.

**Evidencia**:
- Estudios fisiológicos confirman liberación de epinefrina
- Modulación del sistema inmune
- Tolerancia al frío y control voluntario del sistema nervioso autónomo

## 🚀 Inicio Rápido

### Para Principiantes

1. **Abre** [neuralbeat.app](https://neuralbeat.app)
2. **Usa auriculares** (esencial para binaurales)
3. **Selecciona** el preset **Alpha 10 Hz** (Coherencia Cardíaca)
4. **Presiona** ▶ Play
5. **Sigue** la guía visual del orbe para respirar
6. **Practica** 10 minutos

### Para Meditadores

1. Preset: **Theta 6 Hz** o **Schumann 7.83 Hz**
2. Respiración: 4 rpm (15s por ciclo)
3. Duración: 20-30 minutos
4. Posición: Sentado con espalda recta
5. Opcional: Añadir retención llena 4s

### Para Trabajo Profundo

1. Preset: **Beta 16 Hz** + **Box Breathing**
2. Duración: 45-90 minutos (con descansos Pomodoro)
3. Volumen: Bajo, apenas perceptible
4. Combinar con música instrumental si lo deseas

### Para Activación

1. Preset: **Wim Hof Method**
2. Momento: Por la mañana (nunca antes de dormir)
3. Rondas: 3-4 (15-20 minutos total)
4. Seguir instrucciones del orbe
5. Presionar "Inhalar ahora" cuando necesites respirar en la retención vacía

### Para Sueño

1. Preset: **Delta 2.5 Hz**
2. Momento: 30-60 min antes de dormir
3. Posición: Acostado o reclinado
4. Oscuridad total
5. Respiración: 3 rpm (ultra-lenta)

## ⚠️ Contraindicaciones

**NO usar si tienes**:
- ❌ Epilepsia o trastornos convulsivos
- ❌ Marcapasos o dispositivos cardíacos implantados
- ❌ Embarazo (consultar con médico)
- ❌ Trastornos psicóticos o esquizofrenia
- ❌ Apnea del sueño no tratada (presets con retenciones)

**Precauciones**:
- ⚠️ No combinar con alcohol o sedantes
- ⚠️ No usar mientras conduces o operas maquinaria
- ⚠️ Comenzar con volúmenes bajos y sesiones cortas (5-10 min)
- ⚠️ Detener si aparece mareo intenso, palpitaciones irregulares o hiperventilación involuntaria

**Disclaimer**: Herramienta educativa y de bienestar. No constituye diagnóstico médico. Consulta a un profesional ante cualquier condición de salud.

## 🛠️ Tecnología

- **Frontend**: Vanilla JavaScript (ES6 modules)
- **Audio**: Web Audio API (AudioContext, OscillatorNode, GainNode, AnalyserNode)
- **Visualización**: Canvas 2D API con requestAnimationFrame
- **Arquitectura**: Modular
  - `app.js` - Estado y lógica principal
  - `audio.js` - Motor de audio binaural
  - `breath.js` - Motor de respiración
  - `viz.js` - Visualizaciones en tiempo real
  - `presets.js` - 27 presets con metadata completa
  - `i18n.js` - Traducciones (6 idiomas)

- **Sin dependencias externas**: 100% código nativo del navegador
- **PWA ready**: Funciona offline
- **Responsive**: Desktop y mobile

```javascript
    binaural: true,

    pattern: "coherencia",
    bpm: 6,
    ratio: 1.0,
    holdFull: 0,
    holdEmpty: 0
  },
  
  tuning: { audio: {...}, breathing: {...} },
  markers: { positive, adjust, unexpected, stop },
  guide: { when, duration, sequence, contraindications }
}
```
